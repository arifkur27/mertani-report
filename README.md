# Merapi Tani Instrumen Daily Report

Sistem laporan harian Merapi Tani Instrumen dengan TanStack Start, React,
Tailwind CSS, dan Supabase.

## Development

Pastikan Node.js dan npm sudah terpasang, lalu jalankan:

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
